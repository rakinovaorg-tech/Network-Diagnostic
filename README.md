**Network Diagnostic Tool**

A Simple Python Tool That Checks Basic Network Information

-> What It Checks?
   
   -HostName
   -IP Address
   -Default Gateway
   -Network Interface
   -Network Address
   -Internet Connection Status
   -Network Latency

-> Technologies Used
   
   -Python3
   -Kali Linux
   -Linux Networking Commands

-> How To Run?

   Open The Terminal And Open The Project Folder :
     #cd network-diagnostic
   
   Then Run:
    #python3 network_diagnostic.py

   To View Python Code And README.md File Content On Your Linux Terminal
   RUN : cat network_diagnostic.py
         cat README.md
   
   To View File Names And File Size Run: ls -l 
 (For Name Only one item per line, use ls-1)
